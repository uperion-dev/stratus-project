FROM THE 1.6.7 IN-GAME REVIEW

Water & reflections

Water is at the heart of Stratus: clear shallows, native texture, reflections and the transition beneath the surface.

At the surface
The water blends sky and visible scenery reflections with the world below. Native texture and biome colour help it belong in each environment.
Below the waterline
Colour and absorption respond to the submerged part of the view, so the transition above the surface stays connected.
Across different worlds
Clarity, colour, ripples and reflection choices can be adjusted in-game, with the original world geometry preserved.

Questions & answers

What is the Stratus Project?

Stratus Project currently brings together a Minecraft server and a Minecraft Java shader. Both are being developed, with room for more projects in future.

What is the Stratus shader?

It is a Minecraft Java shader for Iris, exploring natural water, familiar light and a customisable atmosphere while preserving the game’s textures and block geometry.

Can I join the server?

The server is being developed and connection details will be shared when they are ready. Bedrock connectivity is still being checked.

Can I use the server without the shader?

Yes. The shader is a separate client-side visual option; the Minecraft server can be enjoyed independently.

What do the showcase images show?

They are real in-game shader captures from naturally generated worlds. Each image identifies the shader version used.

What is being worked on?

The Upcoming page brings together server and shader work. Items are labelled as development or planned checks, and shader release candidates are separate from finished releases.

Compatibility and progress

Stratus is designed for Minecraft Java with Iris. The recorded reference setup uses Minecraft 1.21.11, Iris 1.10.8 and Sodium 0.8.14; other setups may behave differently.

The 1.7.0 candidate has been loaded and reviewed in selected scenes. Waterline, moving-scene and final performance checks remain in progress.
